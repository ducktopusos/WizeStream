On-device models for sensitive content detection.

The models are not bundled in the APK. Selecting an AI option downloads them
to app-private storage from this project's GitHub release and verifies SHA-256.

1) nsfw.tflite
   Explicit-content classifier: GantMan/nsfw_model MobileNetV2 140x224 TFLite,
   the family used by nsfwjs/HaramBlur. Input [1,224,224,3] RGB in 0..1;
   output [drawings, hentai, neutral, porn, sexy].
   Source: https://github.com/GantMan/nsfw_model (MIT). See nsfw-model-LICENSE.txt.
   SHA-256: 380f98f7685f9d8a386f8cc595b6dfcb972989aae3d1b8b270d3a4a5b96fab40

2) person.tflite
   Full-body detector: TensorFlow EfficientDet Lite0 (COCO), int8, input
   [1,320,320,3] RGB bytes. Outputs decoded boxes, classes, scores and count;
   class 0 is person. Several people can be detected in one frame.
   Source: https://www.tensorflow.org/hub/tfhub_modules/efficientdet/lite0/detection
   (Apache-2.0). See person-model-LICENSE.txt.
   SHA-256: 2e04c53bfeac0ac2a30c057c7e2a777594ce39baaac35a92f74fb1e8c4fc4e0b

3) gender.tflite
   Gender classifier used on the head region of each detected body.
   Source: https://github.com/shubham0204/Age-Gender_Estimation_TF-Android
   (MIT License; model trained by that project's author on UTKFace).
   See gender-model-LICENSE.txt.
   Input [1,128,128,3] RGB in 0..1; output [1,2] in the order [male, female].
   SHA-256: 7ab000d530a005ccd605a2826485b23d08690d0e4fb23bc4589a5b03861750c0

Bodies are located by the person detector, not estimated from faces. Gender is
inferred from a head crop of each detected body. All inference happens locally;
no bitmap ever leaves the device.
